# Phase 2 operator prompts

This directory stores the operator-approved Codex prompts used during Phase 2.
Save each prompt here before its corresponding implementation stage begins.
Prompts are historical engineering records and must not be rewritten later merely
because implementation evolves. Preserve substantive instructions faithfully;
do not replace prompts with summaries.

Use `phase_2_stage_<N>_<short_description>.md` for future stage prompts.
Reports remain under `docs/codex/reports/`. Prompts are instructions, not
acceptance evidence by themselves; implementation and validation reports provide
that evidence. This directory is documentation, not a prompt execution framework.
